# Перевірка форми заявки через Playwright MCP

**Умови сесії.** Нова сесія Claude Code, у `/mcp` увімкнено **лише `playwright`**;
`supabase`, `vercel` і всі дев'ять конекторів claude.ai вимкнені перемикачем.
Правило курсу: браузерний сервер водночас пише й є каналом назовні, тож він ніколи
не працює в одній сесії із Supabase. Застосунок запущено локально (`npm run dev`).
Сервер піднято з `--isolated --no-webmcp --allowed-origins http://localhost:3000`.
Чинні deny-правила: `browser_run_code_unsafe`, `webmcp_*`, `browser_file_upload`,
`browser_drop`, `browser_evaluate`.

## Запит

> Відкрий http://localhost:3000, заповни форму заявки тестовими даними, відправ, перевір консоль і
> мережу. Інших адрес не відкривай.

## Ланцюжок інструментів

Агент зробив 7 викликів сервера `playwright`. Усі вони були з переліку `allow` у
`.claude/settings.json` — навігація, знімок сторінки, заповнення полів, відправка,
читання консолі й мережі. Жодного запиту на інструмент поза списком не виникло:
`browser_network_request` (однина, з заголовками й `Cookie`), який навмисно не внесено
ні в `allow`, ні в `deny`, агенту не знадобився, тож і запиту на схвалення не було.

## Чи відправилась форма

Так. Після відправки на сторінці з'явилося «Дякуємо! Заявку отримано.»

Тестові дані: Тест Тестенко, test@example.com, телефон, бюджет «$500–1500 / міс.»,
опис «Тестова заявка: потрібен лендінг.» Чекбокс розсилки не вмикався.
Дані синтетичні, справжніх персональних даних у форму не вводилося.

## Консоль

Помилок і попереджень немає. Лише два службові повідомлення: підказка про React DevTools
і `[HMR] connected` від дев-сервера.

## Мережа

Після відправки — один запит: `POST http://localhost:3000/`, статус 200. Це Server Action,
а не виклик API-роуту. Плюс 22 статичні запити (скрипти й стилі) під час завантаження сторінки.
**Запитів на зовнішні адреси не було.**

## Що з цього видно про права

- `--allowed-origins http://localhost:3000` тут не спрацьовував як межа: агент і не намагався
  вийти за localhost. Вендор прямо пише, що це зручність, а не межа безпеки, і на редиректи
  вона не діє.
- Усі потрібні для перевірки форми дії вкладаються в десять точних імен в `allow`.
  Ширший доступ не знадобився — підтвердження, що список не треба розширювати «про запас».
- Вікно Chrome на Windows видиме, тож за маршрутом агента можна стежити очима.
  Після перевірки вікно закрито.
